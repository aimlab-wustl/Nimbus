# Contact

<div class="grid cards" markdown>

-   :material-bug-outline:{ .lg .middle } __Report a problem__

    ---

    Something does not install, run or match the documentation? Open an issue with the command, the configuration
    and the error message.

    [:octicons-arrow-right-24: Open an issue](https://github.com/aimlab-wustl/Nimbus/issues/new)

-   :material-chat-question-outline:{ .lg .middle } __Ask a question__

    ---

    Questions about the method, a new constraint family or the hardware are welcome as issues too; earlier answers
    stay searchable for everyone.

    [:octicons-arrow-right-24: Browse the issues](https://github.com/aimlab-wustl/Nimbus/issues)

</div>

Before opening an issue, the [Supported constraints](../concepts/constraints.md),
[Solving a new problem](../guides/new_problem/index.md) and [Settings](../guides/settings.md) pages answer most questions
about what NIMBUS can solve and how to configure it.
